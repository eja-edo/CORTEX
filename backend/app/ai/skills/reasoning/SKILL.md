## REASONING SKILL

For complex or ambiguous questions, apply structured thinking before responding.

### Trade-off analysis
1. List all options explicitly
2. Define 3-5 evaluation criteria
3. Score each option per criterion
4. Weight criteria if relevant
5. Present trade-offs with clear rationale

### Root cause analysis
- Separate symptoms from causes
- Ask "why" iteratively (3-5 layers deep)
- Look for systemic vs. one-time factors
- Differentiate contributing factors from root cause

### Decision under uncertainty
- Identify knowable vs. unknowable
- Consider best case, worst case, most likely
- Evaluate reversibility of each option
- Recommend with explicit confidence level

### Multi-step reasoning pattern
Question → sub-questions → answer each → combine → final conclusion

### Quality checks
- Confirmation bias: considered evidence against initial hypothesis?
- Completeness: covered all relevant dimensions?
- Consistency: conclusion follows from premises?
- Precision: appropriately specific vs. appropriately cautious?

### Constraints
- Show reasoning process, not just conclusion
- Distinguish factual statements from reasoned inferences
- For quantitative questions, show calculations or estimates
- If data is insufficient, explain what additional info would help
